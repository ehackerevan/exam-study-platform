# 學習者操作簡化（2026-10-21）

## 七項交付

1. 首頁每科只一張卡，提供繼續學習與開始練題；純題庫只留練題。科目與版本提示保留。
2. 總覽把繼續閱讀、十題練習及錯題入口放在統計之前；閱讀沿用上次章節／小節位置，顯示待複習題數。
3. 測驗預設十題；知識點、章節、考期、精選題組及其他題數收到原生 details「調整出題」中，功能保留。
4. 章末原有十題直接作答不變；全答完顯示成績、重練本章錯題、下一章（末章回總覽）。重練只清本輪錯題的暫存，不刪歷史進度。
5. 回饋優先顯示結果與正確答案，有對應教材才顯示返回；Google 延伸查詢收合，點開連結才傳送題幹。修正亮暗色回饋文字可讀性。
6. 已練題數計不重複 ID；正確率明示包含重練；顯示待複習知識點前五項，依目前仍錯的題數排序。分類重疊時一題可以出現在多個知識點。
7. 手機送出／下一題固定於螢幕底部，章節目錄仍按需展開；修正卡片 hover transform 造成固定按鈕偏移及點擊不穩的問題。目錄按鈕改為緊湊高度。
