## 使用者流程與維護

使用 `dist/index.html` 選科；有教材的科目先讀章節再做十題練習，完整題庫依知識點、章節或考期出題；錯題集中重練。進度仍保存在瀏覽器，請定期匯出備份。教材與題庫來源保留原位置，沒有再建立第二套內容或追蹤系統。

## 限制與未執行事項

- 按指示停止逐題語意及現行法規複核。消金、衍生性、投資型保險、人身及產險未做內容審查；消金只隨共用流程重新建立現有來源的機械索引與輸出。
- 統計是題庫知識點／文字命中，不等同官方命題比例或法規效力審定。過往來源缺口（ESG 候選對應、AML 截斷／答案狀態、信託「自易交易」）仍依先前報告保留，不猜改。
- 證基會 116 年題庫自 2027-01-01 適用，頁面仍保留版本提示。
- E2E 使用本機 Windows Chrome／Edge；未用實體手機驗收，也未驗證其他作業系統。建置需要 Node.js 及 Python。
- 六科延後寫出能避免驗證／編譯失敗造成部分更新，不保證程序在寫檔途中被終止時有交易式回滾。
- 共用 QA Lab runner 不存在，採本專案實際瀏覽器腳本驗收。未部署，保留既有未提交修改。
