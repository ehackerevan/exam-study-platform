# Study Pack Compiler

把教材與來源題庫編譯成單一 HTML，離線閱讀、作答並保存進度。

## 開始學習

開啟 [學科目錄](dist/index.html)，選擇「教材閱讀」或「題庫練習」。不需安裝程式或登入帳號。每科主導覽為「教材、測驗、設定」；教材搜尋收在閱讀頁，學習進度可於章節末展開。測驗頁保留「練習 10 題」與「複習錯題」，其他出題方式在進階設定。全科備份在學科目錄，單科進度備份在設定中。

- 讀完一章，直接做下方 10 題練習，再標記已讀。
- 測驗可依章節、知識點或歷屆考期出題；也可隨機抽題與複習目前錯題。
- 歷屆考期按原題號排列；提前結束時，只結算已答題目。
- 進度留在目前瀏覽器，可在「設定」匯出備份或匯入到另一台裝置。同一科的閱讀與測驗共用進度。
- 錯題重練只收最後一次答錯的題目；答對後會移出待加強清單。
- 「查答案」需連網，會將題幹送到 Google 並開啟新分頁。

金融市場常識與職業道德預設使用[證基會 113 年版](https://webline.sfi.org.tw/T/ethics/download.asp)：金融市場常識 504 題、職業道德 616 題，適用至 2026-12-31。已套用證基會 113/9/23 官方修訂表，將職業道德第 279 題答案更正為第 4 項。[116 年版](https://www.sfi.org.tw/News?id=2675)自 2027-01-01 起適用；目前 113 年版與原始 116 年版分別保存在教材目錄及 `歷史資料/金融市場常識與職業道德題庫_證基會116年版/`。題目與答案依官方題庫及勘誤整理，不代表逐題核對現行法規效力。

每頁可單獨攜帶；「學科目錄」返回連結需保留目錄 HTML 在原來的相對位置。瀏覽器限制或清除網站資料可能影響進度，請定期備份。

金融市場常識與職業道德的 113／116 年版各自保存進度，避免相同題號對應到不同內容。舊版未區分版次的瀏覽器紀錄仍保留，但不自動合併，首次使用新版識別碼時會從空白進度開始；原有進度備份檔也請保留。

## 新版教材整合

六科共 38 章、167 個知識段落已整合至正式閱讀模式，保留原有進度識別碼與章末十題。閱讀與教材搜尋使用新版教學段落；來源段落留在資料中供統計與核對。

## 維護與重建

編譯器使用 Node.js 22 以上；題庫統計使用 Python 3。核心建置不需第三方 npm 套件。

```sh
# 更新統計並產生教材、範例、目錄與共用樣式
npm run build:ui

# 單元測試與離線資源檢查
npm test
npm run validate:offline

# 依序建置、測試、離線檢查、瀏覽器 E2E；任何步驟失敗即停止
npm run verify
```

首次執行瀏覽器驗收前，先執行 `npm ci`，再安裝 Playwright Chromium：`npx playwright install chromium`。`npm run verify` 會執行 `tests/*-browser.cjs` 與端對端流程；GitHub Pages 工作流程會自動安裝瀏覽器及系統相依套件。

建置會先依 canonical 題庫重新產生知識點及法規名稱詞彙統計，避免新增題目後映射過期。這是機械索引，不判斷答案語意或法規效力。教材包會全部驗證與編譯成功後再寫入，避免資料錯誤留下半套輸出。

早期的一次性解析／匯出工具已移至 `歷史資料/已停用維護腳本/` 並禁止執行，避免改掉現行題目 ID、分類或覆寫其他工作副本。正式維護以 `教材/` 資料及上述建置指令為準。統計分析器會依自身檔案位置找專案，可從 `tasks/` Notebook 執行。

## 資料與程式放在哪裡

| 位置 | 用途 |
| --- | --- |
| `教材/` | 在用教材與 canonical 題庫；信託正文來自 `course_data.json` |
| `考古題/` | 本機來源資料、投資型及衍生性商品題庫與歷屆完整題庫頁 |
| `src/core/parser/` | Markdown、CSV、JSON、TXT 匯入與正規化 |
| `src/core/validator/` | 檢查結構、文字編碼、選項與答案索引 |
| `src/core/compiler/` | 把資料、介面與資源嵌入單一 HTML |
| `src/renderer/` | 共用學習介面、文字呈現與樣式 |
| `scripts/` | 統計、建置與離線檢查 |
| `dist/` | 供使用者直接開啟的 HTML |
| `tasks/todo.md` | Current 與完成紀錄 |

共用色票在 `src/renderer/ui-theme.css`。規範用語提示與答案搜尋分別由 `legal-terms.js`、`answer-search.js` 注入，不需在模板另外維護副本。

## 編譯自己的學習包

```sh
node bin/study-pack.js validate ./examples/general-exam
node bin/study-pack.js build ./examples/general-exam ./dist/general-exam.html
node bin/study-pack.js --help
```

支援 Markdown、JSON、CSV、TXT。資料契約見 [study-pack.schema.json](src/core/schema/study-pack.schema.json)，範例見 [examples](examples)，架構說明見 [架構與開發說明](專案文件/架構與開發說明.md)。JSON 答案使用 0 起算索引；CSV／TXT 可用 A、B 或 1、2 等來源標記。缺答案、空白選項或無法識別的答案會被擋下，不會推定成 A。

輸入資料需為 UTF-8，可接受 BOM。題目原文、選項與答案應先對照來源；建置驗證只確認可讀取與可正確執行，不代替內容審定。

## 額外單檔整合版

`npm run build:ui` 也會輸出根目錄與 `dist/學習平台_單檔整合版.html`，內含目錄、六科頁面、金融常識 116 年版、投資型與衍生性商品題庫及歷屆題庫共十一頁，可直接開啟。單檔保留在 GitHub，Pages 沿用分頁版。網站與本機檔案的進度可能分開儲存，轉移前請匯出備份；查答案等外部連結仍需網路。

整合備份使用 `study-pack-complete-backup-v1` 格式。匯入時依學科識別碼還原個人紀錄，教材與題庫維持目前版本；舊備份不必包含後來新增的教材。後續更新須保留既有學科識別碼與 v1 匯入支援；若變更進度格式或識別碼，須提供遷移並保留舊備份匯入測試。含雲端帳號紀錄的備份需在線上登入後還原。

四科官方原卷的 202 份 PDF 正本位於 `考古題/`。2026-10-24 重查發現先前複製到 `歷史資料/00_四科官方題目與解答PDF/` 的 202 份完全相同，已移除多餘副本；該歷史目錄原有的 9 份文字註記保留。PDF 受 `.gitignore` 排除，並非 Git 追蹤檔。先前的 `待刪除/` 已不在目前工作區；Git 仍留有指向其中發布工作樹的失效登錄。

Pages 發布打包時會在公開頁面加入 Cloudflare Web Analytics；`dist`、教材來源及單檔整合版不包含追蹤碼。Web Analytics 網站 token 是公開頁面識別碼，並非 Cloudflare API Token。 學科瀏覽及題目作答的匿名事件已準備以 `analytics/` 中獨立 Worker 彙整；上線後僅發布副本使用，計數方式、查詢及部署前置見 [統計說明](analytics/README.md)。

### 個人題目管理

- 題目右上角可加入收藏或隱藏；章末練習也可操作。隱藏後可立即復原，或到測驗的「已隱藏題目」搜尋、恢復。
- 「練習我的收藏」集中練習收藏題；「只練我的收藏」可搭配章節、知識點或考期。所有測驗排除隱藏題目；章末練習優先補入同章題目，最多十題。
- 隱藏未作答題目不計次數，已提交成績保留。題目同時精選及隱藏時，恢復後才會再次出題。
- 標記按科目版本保存在此瀏覽器，隨既有進度匯出／匯入；舊備份未包含標記時視為空白，不會自動跨裝置同步。歷屆完整題庫瀏覽頁不共用個人標記。

### 手機閱讀

- 章節目錄在手機預設收合，顯示目前章名；閱讀中可用固定小節選單、前後節按鈕與目錄入口跳轉。
- 非流程圖採緊湊對照列；短表格使用可用寬度，寬比較表保留表內捲動。法規對照可展開閱讀；正文、數字與例外保留。
- 章末只保留判斷界線與理解題，避免重抄章首圖解；測驗先呈現開始練習，個人精選及隱藏管理置後。

### 金融常識題庫版本

- 學科目錄及題庫頁可選擇證基會 113 年版（1,120 題）或 116 年版（1,174 題），原有入口預設為 113 年版；兩版均可閱讀導讀及練題。
- 依保留來源標示：113 年版適用至 2026-12-31；116 年版自 2027-01-01 起適用。版本選擇不代表對題目現行法律效力重新審定。
- 兩版進度、錯題、隱藏及精選各自保存，備份不可跨版匯入。即使題號相同，也不會視為同一題合併成績。
- 116 年版建置來源為「歷史資料/金融市場常識與職業道德題庫_證基會116年版」；只在題幹、選項、答案與章節完全一致時沿用 113 年版知識點，其他題目列為「其他／未分類」，未將舊版題數統計冒用為新版統計。
- 網站發布及單檔都包含兩個版本。

### 規則優先的閱讀版面

- 章首概念總覽預設收合，保留鍵盤與節點互動；首屏直接顯示知識點。重複的 CDD 開戶導讀已併入章首。
- 桌面將白話說明與詳細規則對照；含寬比較表的段落保留整欄寬度。手機依核心規則、詳細條件、概念整理／案例順序閱讀。
- 非流程內容採條列，概念整理可展開；正文已有實例表時不重複附例。法規數字與期限保留強調色，章首、一般說明與來源資訊減少標色。
- 章名只在正文完整顯示，目錄入口不重複章名；已讀按鈕移至教材結尾、章末十題之前。章末十題、題庫版次與既有進度機制不變。
