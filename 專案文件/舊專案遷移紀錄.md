# MIGRATION_NOTES.md: 既有 trust-exam-study 遷移評估與架構對比

本文件分析既有專案 `ehackerevan/trust-exam-study`（信託證照教材與歷屆題庫）與全新 `Study Pack Compiler` 之格式差異與遷移策略。

---

## 一、目前格式 (Current Format in trust-exam-study)

1. **題目與資料結構**：
   - 既有題目結構採用精簡壓縮鍵值：
     ```json
     {
       "p": "01",        // 期數 / 章節代碼
       "s": 1,           // 科目代碼 (1: 信託法規, 2: 信託實務)
       "n": 12,          // 題號
       "q": "題目字串",   // 題幹
       "o": ["選項1", "選項2", "選項3", "選項4"], // 選項陣列
       "a": 2,           // 答案 (1-4 代表 A-D)
       "tp": "信託財產獨立性" // 知識點 / 主題
     }
     ```
   - 題目 ID 由函式 `key(q) = \`${q.p}-${q.s}-${q.n}\`` 動態拼裝。

2. **教材呈現**：
   - 使用 Markdown 文本，在網頁前端以 base64 內嵌 Marked.js 執行即時解譯渲染。

3. **作答儲存**：
   - localStorage key: `trust_exam_progress_v1`
   - records 鍵格式為 `01-1-12`，紀錄 `attempts`, `wrong`, `lastCorrect`, `selected`, `lastAt`。

---

## 二、目標格式 (Target Study Pack Schema)

1. **泛用化 Study Pack Schema (`study-pack.schema.json`)**：
   - 脫鉤特定證照與期數，改採標準層級：
     ```json
     {
       "id": "q001",
       "chapterId": "chapter-01",
       "sectionId": "section-01",
       "type": "single-choice",
       "question": "題目內容",
       "options": ["A", "B", "C", "D"],
       "answer": 1,
       "explanation": "答案解析"
     }
     ```
   - `answer` 正規化為 0-based 數字索引（0 代表選項 A，1 代表選項 B）。

2. **教材與題庫一體編譯**：
   - 所有 Markdown 教材在編譯期（Build Time）進行正規化解析與安全性淨化。
   - 產出的 HTML 零外部依賴、內嵌已正規化之 JSON 資料，不再依賴前端 Marked.js 動態解析，啟動速度更快且完全離線可用。

3. **學習進度隔離**：
   - key 格式改為 `study-pack.{packId}.progress`，支援多教材獨立保存，不互相衝突。

---

## 三、格式差異對照表

| 項目 | 既有 `trust-exam-study` | `Study Pack Compiler` |
|---|---|---|
| **題目識別** | `p`, `s`, `n` 複合鍵 | 唯一字串 `id` (如 `tx001`) |
| **章節關聯** | `p` 期數 + `s` 科目 | `chapterId`, `sectionId` |
| **知識點分類** | `tp` (純字串) | 關聯至章節小節之 `keyPoints` |
| **答案索引** | 1-based (1~4) | 0-based (0~3)，且支援多選陣列與是非題 |
| **題型支援** | 僅單選 | 單選 (single-choice)、是非 (true-false)、多選 (multiple-choice) |
| **題目詳解** | 無（原題庫僅提供 Google 搜尋連結） | 內建 `explanation` 詳解解析欄位 |
| **進度備份** | 僅本機快取無匯出 | 支援完整的 JSON 備份 (Export) 與還原 (Import) |
| **弱點分析** | 僅累計錯誤次數排序 | 具備門檻分析 (<60% 加強, 60-80% 未穩定, >80% 穩定) |

## 四、自動化遷移策略 (Migration Strategy)

若未來欲將 `trust-exam-study` 全量 2,722 題考古題完整遷移至 Study Pack：

1. **題目資料轉換腳本 (Transformer Script)**：
   ```javascript
   function transformLegacyQuestion(legacyQ) {
     return {
       id: `tx-${legacyQ.p}-${legacyQ.s}-${String(legacyQ.n).padStart(2, '0')}`,
       chapterId: legacyQ.s === 1 ? 'trust-law' : 'trust-practice',
       sectionId: slugify(legacyQ.tp || 'general'),
       type: 'single-choice',
       question: legacyQ.q,
       options: legacyQ.o,
       answer: Number(legacyQ.a) - 1, // 1-based 轉 0-based
       explanation: `本題出自第 ${legacyQ.p} 期測驗科目【${legacyQ.s === 1 ? '信託法規' : '信託實務'}】，核心知識點：${legacyQ.tp || '無'}`
     };
   }
   ```

2. **分階段平滑過渡**：
   - 階段一：已於 `examples/trust-exam-migration` 完成概念驗證，證明 Study Pack 能完美相容信託教材與題型。
   - 階段二：撰寫批次腳本將既有 JSON 題庫轉為 CSV 或直接輸出為 `pack.json`。
   - 階段三：利用 Study Pack Compiler 直接編譯產生 `dist/trust-exam.html`，達到完全離線且功能更豐富的新版單檔學習網站。
