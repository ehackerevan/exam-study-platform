# 雲端學習進度

正式網站每科的「設定／登入」可首次建立代號或登入。代號需 12–64 個英文字母、數字或 `!@#$%^&*_.-`，且含字母和數字；代號等同密碼，應選用不容易猜到且未用於其他網站的代號。遺失時沒有身分驗證管道，無法找回。

每科進度保存在 D1，瀏覽器亦保留該帳號的本機副本；登入首次進入未有雲端進度的科目時，可選擇複製該科訪客紀錄。其他帳號、訪客及不同科目使用獨立本機紀錄。網路中斷時本機保存，恢復連線後重試；裝置同時更新造成衝突時停止上傳，使用者可匯出本機進度或選擇雲端進度，系統先保留本機備份。清除本教材進度會同步清除該科進度。離線 HTML 不使用雲端。

Worker 與 GitHub Pages 不同網域，登入使用 Secure、HttpOnly、SameSite=None、Partitioned Cookie；不支援或封鎖跨網站 Cookie 的瀏覽器可能無法登入，原本訪客功能仍可使用。使用公用電腦時應登出，並注意該瀏覽器仍可能留有本機進度；不應將機密或個人敏感資訊放入學習進度。

代號使用伺服器密鑰產生查詢索引，並以獨立隨機 salt 和 scrypt 保存驗證值；工作階段只保存 token 的雜湊。Worker 限制網站來源、請求大小及頻率。Cloudflare 的頻率限制是各地區近似值，不能保證阻止所有代號猜測；代號長度和不可預測性仍重要。

## 部署

在現有 `study-pack-metrics` D1 先執行 `schema.sql`，它只新增 `sync_` 資料表與索引，不更動原統計表；以 `wrangler.jsonc` 部署 Worker，使用 Worker secret `SYNC_PEPPER`（至少 32 隨機位元組）。**不得更換或遺失此密鑰**：帳號查詢索引依賴它，換掉後既有代號將無法登入。密鑰不寫進儲存庫或日誌。Cloudflare Worker 和 D1 Free 額度與其他服務共用，達限制時保留本機進度並提示同步失敗。

`.github/scripts/prepare-pages.mjs` 僅將登入客戶端注入正式線上學科頁；本地離線產物保持原先的離線行為。發布前執行 `npm run verify` 與使用隔離資料庫的實際跨裝置測試。回滾先恢復前一版網站與 Worker，不刪除 D1 資料或密鑰。
