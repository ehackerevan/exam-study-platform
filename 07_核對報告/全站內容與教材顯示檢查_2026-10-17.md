# 全站內容與教材顯示複核

日期：2026-10-17  
範圍：整合資料夾 58 個 HTML 頁（含目錄）、35 份教材 Markdown、四科離線教材題庫包與防制洗錢既有版，以及所有課程圖像資產。

## 結果

- **頁面文字與編碼：**58 個 HTML 與 35 份教材 Markdown 均可用 UTF-8 解碼，未發現替代字元或常見亂碼。靜態頁面文字未發現 Lorem ipsum、TODO、框架名稱或其他常見測試佔位文字。教材章節、題庫操作、目錄連結及警語保留。
- **教材路徑：**修正金融科技、消費金融及洗錢教材目錄中的 3 個失效章節連結。全教材 67 個本機 Markdown 連結有效；36 個圖片連結皆有替代文字且資源存在。單檔離線包的章節清單改為純文字，避免讀者點到套件未附的 Markdown 原始檔。
- **內容修正：**按主管機關現行法規與公告修正消費金融利害關係人授信例外、第三方支付申請門檻與期限、FIDO／通行密鑰的裝置差異、金融監理沙盒排除範圍、洗錢防制的帳戶收集／交付刑責及實質受益人例外，以及 ESG 揭露適用範圍、基金比重與碳費新納管時點。保留警語與錯誤選項示例，移除不精確的絕對化說法。
- **離線教材包：**依 35 份教材 Markdown 更新內嵌教材章節；金融科技力 20 節、消費金融 14 節、永續發展 24 節、洗錢資恐新版與既有版各 15 節。既有圖片逐張保留，未重建圖表。
- **圖像檢查：**82 個 SVG 與 13 個正式版教材包內嵌 PNG 均成功轉為預覽並逐張檢視，未見文字裁切、元件重疊或連線偏移。少數中文標題會依方框寬度換行，但完整可見。
- **題庫：**四科題目與答案資料未更動，並與 Study Pack Compiler 的題目 payload 完整比對一致：金融科技力 839 題、消費金融 2,989 題、永續發展 1,267 題、洗錢資恐 2,388 題。新版與既有版洗錢包題目數相同。

## 驗證與限制

- `py -3 07_核對報告/verify_integrated_ui.py` 通過：58 個 HTML、57 個返回目錄連結、題庫互動與安全外連、內嵌圖表有效性、題目 payload 對照及 57 頁 SHA-256 清單。
- 教材章節以整合資料夾內 Markdown 為準，可能與 Compiler 中的教材章節結構不同；驗證仍逐題比對完整題目 payload，並檢查題庫互動及圖表數量。
- 本機瀏覽器安全政策拒絕檢視 `file://` 頁面，因此未作頁面實際瀏覽器截圖驗收；圖檔以本機 SVG／PNG 渲染器目視檢查。官方歷屆題目 PDF 本輪未重新抽取；題庫 payload 未變更。
