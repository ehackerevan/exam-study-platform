## 限制與未檢查事項

這次核對以官方答案表及既有抽取後題目資料為準，沒有逐頁人工重讀每一張掃描 PDF 的 OCR 字元；信託 JSON 題目已與原有 2,722 題頁面比對一致，第 47 屆題目使用既有補充 JSON。官方答案表缺少的 8 題無法納入。離線頁中的 Google 搜尋按鈕需網路。信託資料夾內另留一份重複的 `sync_data` 副本，因清理操作被工具拒絕而保留，未嘗試繞過。

## UI 一致化與題庫功能驗收（2026-10-16）

- 五科整合目錄共 58 個 HTML 頁面；根目錄 `index.html` 為目錄，其餘 57 頁均有統一頂部導覽，返回連結皆解析至整合目錄。
- 四科 Study Pack 各新增一致的歷屆題庫瀏覽介面：考期、章節／知識點篩選、關鍵字搜尋、答案與解析揭露、單題作答、篩選結果隨機練習，以及既有錯題練習。消費金融題庫另包含考科／組別篩選；防制洗錢複選題答案標示已驗證。
- 驗證腳本 `verify_integrated_ui.py` 檢查了 4 科共 8 個內嵌 JavaScript 區塊語法、57 個目錄返回連結、介面使用的 CSS 變數、題庫互動模擬；四科題目資料均與 Study Pack Compiler `dist` 原稿完全相同，未改動題目內容或答案。此項資料比對維持先前逐題官方答案核對所得結果，收錄題答案差異為 0，疑義題與送分題未收錄。

## 使用者角度的介面盤點

### 已修復

信託整合頁原本以 CSS Grid 配置兩列，但加上目錄導覽後，直接子項目變成「目錄列、信託分頁列、內容列」三列；內容列落入沒有明確高度的隱含列，教材與題庫 iframe 因而看不到。已把外層改成三列，並以 DOM 模擬確認教材與題庫兩個內嵌畫面都載入、可切換及可由教材內訊息返回。實際瀏覽器畫面仍受本機頁面存取限制，尚未目視確認。

### 全站 UI 改善與驗收（2026-10-16）

- 四科 Study Pack 改為信託式「教材／歷屆題庫」兩個主分頁。教材區保留總覽、教材閱讀、教材搜尋、速查四個次導覽；設定移至標題列，開啟後可返回進入前的畫面。原測驗設定仍可由題庫入口及總覽進入。
- 五科每題題幹旁均提供 Google 搜尋外連；四科單科包、四科彙整題庫及信託核對版均使用安全的新分頁連結設定。此功能需網路，其餘教材與題庫操作仍可離線使用。
- 四科題庫篩選改為可展開／收合，預設展開；目錄的彙整題庫、分類索引及核對報告改收在預設收合的輔助連結區。
- `verify_integrated_ui.py` 驗證 58 個 HTML（57 個返回目錄連結）、四科兩主分頁與教材次導覽、設定返回、題庫篩選及搜尋、單題作答、篩選測驗、錯題練習、測驗設定、Google 題目外連、信託畫面切換、四科 8 個 inline JavaScript 區塊及信託外層 JavaScript 語法，以及題庫資料與編譯原稿一致；全部通過。
- 瀏覽器視覺驗收未執行：本機 `file://` 頁面被瀏覽器安全政策拒絕，未以其他方式繞過。Node 語法與 DOM 模擬通過，但窄螢幕實際視覺細節仍待本機目視確認。
