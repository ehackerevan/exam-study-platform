# 五科教材與題庫整合資料

## 使用方式

開啟同資料夾內的 [index.html](index.html)，即可進入五科離線教材與題庫。教材和題庫頁已集中分類；原來源檔以複製方式保留。

## 分類目錄

- `00_四科官方題目與解答PDF`：四科官方歷屆題目與答案 PDF，共 202 份。
- `00_既有核對報告`：來源專案原有的清洗與驗證報告。
- `01_信託業務人員`：教材來源、官方歷屆資料、既有頁面、答案資料，以及核對後離線頁。
- `02_金融科技力`、`03_消費金融內控稽核`、`04_永續發展基礎能力`、`05_防制洗錢與打擊資恐`：各科教材來源和離線教材題庫包。
- `06_四科彙整題庫`：既有四科完整題庫頁與來源版。
- `07_核對報告`：本次比對摘要、逐筆資料、PDF 抽取記錄與可重現的核對 Notebook。

## 信託題庫篩選結果

核對版收錄信託題目 2,852 題，含第 47 屆 130 題。逐題比對官方答案表，收錄題答案不一致數為 0。官方答案表另有 8 個題目鍵未出現在現有題庫，其中 2 題為多答案、1 題送分、5 題為單一答案題；這 8 題均未納入核對版。第 53 屆信託實務第 53 題官方更正答案按單一答案 2 核對。

`03_既有教材與題庫頁` 內原有頁面是來源存檔，題庫頁為 2,722 題，不含第 47 屆；請從 `index.html` 開啟 `06_答案核對版` 中的 2,852 題版本。

## 閱讀注意事項

- 四科完整題庫頁含 7,484 筆來源抽取紀錄；四份單科教材題庫包共 7,483 筆。差異是永續發展 114-4 第 44 題在完整題庫抽取中有兩筆、單科包有一筆；題目答案和內容相同。細節見核對報告。
- 五科題庫的每題卡片均提供 Google 搜尋外連；使用該連結需要網路，其餘教材、篩選、作答及題庫功能仍可離線使用。
- 因先前清理命令遭工具拒絕，信託 `04_題庫與解答資料\sync_data\sync_data` 仍留有一份重複副本；頂層 `sync_data` 才是本整合使用的核對來源。未刪除任何來源檔。
- 原始教材、來源專案檔案及未提交修改均未改寫；整合目錄是複製出的工作副本。

## 統一導覽與題庫功能

- `index.html` 是五科目錄；其餘 57 個 HTML 頁面均有一致的「五科教材與題庫」頂部導覽列，可直接返回目錄。
- 四科 Study Pack 統一採信託式「教材／歷屆題庫」主要分頁；教材區保留總覽、教材閱讀、教材搜尋、速查次導覽，設定放在標題列。題庫篩選可展開／收合；答案與解析可展開查看，也能單題作答、依篩選結果隨機練習、練習錯題或進入測驗設定。
- 五科題目卡均提供 Google 搜尋外連；信託核對版保留原有題庫互動，並加上相同的返回目錄導覽。信託外層版面已修正，避免內容區被擠成零高度。
- 目錄的彙整題庫、索引與核對報告收在可展開的輔助連結區，五科主入口保持在前。
- UI 驗收紀錄與可重跑檢查見 `07_核對報告/ui_harmonization_report.json` 及 `07_核對報告/verify_integrated_ui.py`。
