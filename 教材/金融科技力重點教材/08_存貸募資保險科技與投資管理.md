# 第 08 章：存貸、募資、保險科技與投資管理（無專章主題補編）

---

##  本章學習導航與核心地圖

本章補齊官方簡章（八）保險科技、（九）存貸、（十）募資、（十一）金融科技下的投資管理四項，稽核窗第 15–22 屆共 106 題（22.1%）原無專章覆蓋。本章出題焦點在於：
1. P2P 借貸營運模式與風險
2. 群眾募資四型與股權型風險
3. 保險科技（UBI、科技中立原則、數位保險公司資本額）
4. 金融科技下的投資管理（演算法／程式／高頻交易、社群投資）

---

##  一、存貸：P2P 借貸（Peer-to-Peer Lending）

依據中央銀行 2018 年第 3 季理監事會後資料與 2019 年報告，P2P 借貸平台營運模式分為五種：

| 營運模式 | 運作說明 | 代表業者 |
| :--- | :--- | :--- |
| 傳統模式 | 僅協助資訊中介，不涉入撥貸 | Zopa（英國，全球首家 P2P 借貸平台） |
| 公證模式 | 銀行參與合作撥貸，而後將債權轉讓給投資人 | Lending Club（美國） |
| 保證收益模式 | 平台向出借人承諾一定收益 | 陸金服、點融（中國） |
| 資產負債表模式 | 平台以自有資金撥貸，帳載於本身資產負債表內，而後透過轉讓債權予投資人或機構投資人獲取資金 | SoFi（美國） |
| 發票交易／應收帳款承購模式 | 平台業者提供應收帳款承購服務 | Market Invoice（英國） |

- P2P 借貸的優點：增進資金使用效率、網路交易無地域性、人事及設備成本降低、直接媒合借款者與貸款者、減少對金融中介機構的依賴。
- P2P 借貸的主要風險：資訊不對稱、詐欺風險、流動性風險、平台倒閉風險、洗錢與資恐風險；出借人承擔借款人信用風險，平台本身不保證本息（保證收益模式除外，該模式以平台信用背書，風險集中於平台）。
- 美國監理：P2P 借貸平台須向美國證券交易委員會（SEC）及各州證券監管機構註冊，無新訂專法，以既有證券法規納管。

##  二、募資：群眾募資（Crowdfunding）

群眾募資依回報性質分為四型：

| 類型 | 運作說明 | 出資人取得 |
| :--- | :--- | :--- |
| 捐贈型 | 純公益捐助，無對價回報 | 無回報（公益目的） |
| 回饋型 | 贊助專案，取得產品、服務或紀念品等非金錢回報 | 產品或服務回饋 |
| 股權型 | 出資取得新創事業股權，分享未來成長收益 | 股權 |
| 債權型 | 出資借貸給專案方，取得利息收益 | 債權（本金加利息） |

- 股權型群眾募資的主要風險：股權稀釋風險、資訊不對稱風險、流通性風險（股權不易轉售變現）。
- 台灣股權群募：須由證券經紀商與櫃買中心簽約辦理，透過櫃買中心股權群募平台進行。
- 與 P2P 借貸的區辨：群眾募資是「向不特定大眾募集資金辦專案或創業」（募資端），P2P 借貸是「個人對個人的借貸媒合」（存貸端）；債權型群募與 P2P 借貸皆涉借貸，但前者以專案募資為目的、後者以個人借貸媒合為目的。

##  三、保險科技（InsurTech）

- 使用基礎保險（Usage-Based Insurance, UBI）：依實際使用行為計費的保險，例如依駕駛開車時間、里程與駕駛習慣評估風險、決定保費；改變傳統以人口統計或固定費率為主的定價模式。
- 科技中立原則：監理不因技術形式不同而差別對待，同一保險業務不論以傳統通路或科技方式提供，均適用同一監理要求。
- 保險科技的應用：協助業務員在適當的時機行銷保險業務、線上投保與理賠流程自動化、運用大數據與 AI 進行核保與風險評估、結合物聯網裝置（如車載裝置、穿戴裝置）蒐集風險資料。
- 數位保險公司最低實收資本額（《保險業設立許可及管理辦法》第 29-3 條，現行版，核對日期 2026-11-21）：數位財產保險公司新臺幣 5 億元；**數位人身保險公司新臺幣 10 億元**；發起人及股東之出資以現金為限，實收資本額應全數由發起人認足，不適用第 9 條公開招募之規定；主管機關得視營業計畫書之業務規模與預算評估要求其增加實收資本額。
- 網路投保：保險科技發展下，消費者得透過網路投保；商品範圍與投保限額依主管機關開放情形與各公司規定辦理。

##  四、金融科技下的投資管理

- 演算法交易（Algorithmic Trading）：以預設演算法自動執行交易決策與下單，依程式規則買賣，降低人為情緒干擾。
- 程式交易（Program Trading）：以電腦程式一次執行一籃子證券的買賣指令，屬於演算法交易的應用形式之一。
- 高頻交易（High-Frequency Trading, HFT）：屬於演算法交易的一種，以微秒級速度進行大量、短線套利交易；伺服器鄰近交易所（共置，Co-location）以縮短傳輸延遲是其關鍵特徵。層級關係：高頻交易 ⊂ 演算法交易；程式交易與演算法交易高度重疊，命題時以題幹關鍵字區辨（「微秒級」「鄰近交易所」指向高頻交易）。
- 社群投資（Social Investing／社群交易）：投資人透過社群平台分享投資觀點、跟隨他人交易策略；平台提供跟單、複製交易等功能，風險在於跟隨者未必理解策略內容與風險。
- 收費模式：以管理資產規模（AUM）按比例收費為主流，取代傳統按交易筆數收取手續費；智能理財顧問（Robo-Advisor）亦採 AUM 收費，費率通常低於傳統投顧（服務流程與再平衡機制詳見第 02 章 §四，本章不重複）。
- 人機結合（Cyborg-advisor）：機器演算法提供投資組合建議與執行，搭配真人理財顧問提供諮詢與客製化服務，結合自動化效率與人性化判斷。
- B2B 投資顧問平台：以機構或理財顧問為客戶，提供投資組合管理工具與演算法模組的平台型服務，與直接面對散戶的 B2C 智能理財顧問區辨。
