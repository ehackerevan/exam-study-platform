##  歷屆題目常見英文縮寫

- ABCD：AI（人工智慧）、Blockchain（區塊鏈）、Cloud Computing（雲端運算）、Big Data（大數據）。
- API (Application Programming Interface)：應用程式介面，軟體與系統間溝通之標準橋樑。
- Open API：開放 API，銀行向第三方服務提供者(TSP)開放之資料介面。
- TSP (Third-Party Service Provider)：第三方服務提供者（如比價網、記帳App新創）。
- FIDO (Fast IDentity Online)：線上快速身分認證聯盟，主打裝置端生物辨識與免密碼登入。
- MFA (Multi-Factor Authentication)：多因子認證，需跨越「所知、所持、所具」兩項以上。
- IaaS / PaaS / SaaS：基礎設施即服務（租毛胚屋）/ 平台即服務（租精裝房）/ 軟體即服務（住飯店）。
- PoW (Proof of Work)：工作量證明（算力挖礦，高耗能）。
- PoS (Proof of Stake)：權益證明（持幣多寡與時間證明，節能）。
- PBFT (Practical Byzantine Fault Tolerance)：實用拜占庭容錯（聯盟鏈首選共識機制）。
- DLT (Distributed Ledger Technology)：分散式帳本技術。
- VASP (Virtual Asset Service Provider)：虛擬資產服務事業（依洗錢防制法採嚴格登記制）。
- STO (Security Token Offering)：證券型代幣發行（受證交法嚴格監理，3,000 萬以下）。
- Robo-Advisor：智能理財顧問 / 機器人理財（基於馬可維茲資產配置自動再平衡）。
- F-ISAC：金融資安資訊分享與分析中心（跨機構資安情資聯防中樞）。
- F-CERT：金融電腦緊急應變小組（資安重大事件應變鑑識）。
- F-SOC：金融資安監控中心（7x24 即時日誌關聯分析）。
- RegTech (Regulatory Technology)：法遵科技（金融機構自我合規用）。
- SupTech (Supervisory Technology)：監理科技（金管會等監理機關專用）。

##  題目判讀重點

1. 「第三方只能代收付，儲值轉帳是電支；日均二十億破頂，半載之內拿執照」：
   - 看到「小額匯兌」、「帳戶儲值」，選項若有第三方支付一律刪除，答案鎖定電子支付機構！日均餘額 20 億元為升格門檻！
2. 「電支資本一三五，儲值帳戶限五萬」：
   - 僅代收付 1 億、收受儲值 3 億、兼營匯兌 5 億；每一電支帳戶儲值上限 5 萬元！
3. 「公鑰是帳號用來驗，私鑰是印鑑用來簽」：
   - 發送交易數位簽章時，永遠使用發送者自己的私鑰；接收者驗證簽章時，永遠使用發送者的公鑰！
4. 「指紋人臉本機留，伺服器上只存公」：
   - FIDO 的生物辨識特徵絕對不出個人手機晶片，雲端伺服器僅存放公鑰！
5. 「沙盒申請無門檻，自然法人皆可玩；洗防資恐不豁免，實驗修法上限三」：
   - 沙盒條例申請人不限金融業，自然人、獨資、合夥與法人皆具申請資格！洗錢資恐絕對不豁免！實驗修法最長上限 3 年！
6. 「STO 限專投，散戶三十萬封頂」：
   - 證券型代幣一般民眾不能隨意買，限專業投資人，自然人上限 30 萬元！
