# 金融市場常識與職業道德題庫（證基會 116 年版）

**注意：本目錄存放的是自 2027 年 1 月 1 日起適用的新版題庫，不是舊版封存。** 目錄名中的「歷史資料」僅表示它與現行 113 年版分開保存。

- 116 年版共 1,174 題：金融市場常識 558 題、職業道德 616 題，自 2027-01-01 起適用；113 年版（1,120 題）適用至 2026-12-31。
- 較 113 年版：常識新增 54 題（第 505–558 題）、實質題幹變動 106 題、選項變動 118 題、答案索引變動 72 題。
- 來源：證基會 116 年版公告 https://www.sfi.org.tw/News?id=2675 ；題庫 PDF 下載專區 https://webline.sfi.org.tw/T/ethics/download.asp 。
- 職業道德第 279 題答案待官方 116 年版 PDF 核實（見修補單 BK-01，條件式）；在核實前不得逕改本目錄 `questions.json`。
