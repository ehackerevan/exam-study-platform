# 各科教材 ELI5 設計預覽

直接開啟 `各科教材_ELI5_獨立預覽.html`，不需其他檔案、伺服器或安裝套件。內含六科、37 章、370 道章末練習。金融市場常識與職業道德維持題庫導讀定位。

學習順序：看圖 → 點選步驟看白話說明 → 生活比喻與理解問題 → 原文對照 → 章末十題。綠藍色票沿用既有設定；手機改為直向圖解，基本內容可在未啟用 JavaScript 時閱讀。

這是獨立設計稿，不加入正式建置或部署，也不讀寫正式作答進度。練習保留來源題幹、選項與答案；本次沒有重新審定法規效力。原教材中的圖形語法轉為文字對照，無內容的分隔段落略去。

## 維護

- `lessons.mjs`：各章白話導讀、圖解節點、比喻限制及理解問題。
- `preview.css`／`preview.js`：預覽版面及互動。
- `build-preview.mjs`：從既有 `dist` 讀取教材、來源答案與章末題目，輸出全部內嵌的 HTML。
- `verify-preview.cjs`：獨立副本離線、全章節、四種寬度、鍵盤及題目來源一致性檢查。

在專案根目錄執行 `node 設計預覽/build-preview.mjs` 重建；執行 `node 設計預覽/verify-preview.cjs` 驗證。驗收證據在 `.qa-artifacts/eli5-preview/`。
