# 各科教材 ELI5 設計預覽

直接開啟 `各科教材_ELI5_獨立預覽.html`，不需其他資源。六科、37 章、370 道章末練習；不讀寫正式學習進度。

## 目前版本：全科逐節深化版（v4）

六科、37 章共 163 個知識段落，每節整合核心概念、圖解、情境與易混淆提醒。保留法規條件、期限及例外；重複的使用說明、統計方法、建置訊息與導讀已整合或移除，來源連結及版本放在章末。

化學式及公式使用離線可讀文字，例如 CO₂e、CH₄、N₂O、SF₆、NF₃ 與乘號。正文中的數字、期限、比例、條號及立即等時間用語以深金色粗體標示；深底 SVG 圖內用亮金色粗體。題目不加提示色，只做符號顯示正規化，答案索引不變。

桌面與手機保持單一閱讀主線；比較表可左右捲動。

來源集中在章末，法規條件與例外直接呈現。內文依現有教材整理，本次未重新審定法律效力。本版已整合正式平台的閱讀模式與單檔版本；保留此獨立預覽供內容檢閱，尚未推送部署。

## 維護

- `lessons.mjs`：各章導讀、互動圖解、比喻與理解問題。
- `cdd-topics.mjs`／`section-topics.mjs`：逐節概念、圖解、情境及易混淆提醒。
- `text-format.mjs`：化學／數學符號正規化、文句清理及數字標示。
- `preview.css`／`preview.js`：版面及互動。
- `build-preview.mjs`：讀取既有 dist 來源與答案，產生單檔。
- `verify-preview.cjs`：離線、全章節、四種寬度、鍵盤及來源一致性檢查。

在專案根目錄執行 `node 設計預覽/build-preview.mjs` 重建；`node 設計預覽/verify-preview.cjs` 驗證。證據在 `.qa-artifacts/eli5-preview/`。

版本紀錄：v1 圖解與收合對照；v2 法規可見並排；v3 統一主線與 CDD 示範；v4 全科逐節深化、符號與文字清理、法規數字標示。詳細交接沿用 tasks/todo.md。

逐節涵蓋與整合／移除原因在 `.qa-artifacts/eli5-v4/coverage.json`；瀏覽器證據沿用 `.qa-artifacts/eli5-preview/`。驗收另比對留存段落中的金額、比例、期限與條號，避免文字清理誤刪數值。

## 正式整合

`npm run build:ui` 先建置來源，再執行本目錄建置器及 `scripts/integrate-teaching.js`，將同一份教學內容編入各科 pack 的 teachingSections。原 sections 留作來源／統計對照；正式閱讀與教材搜尋使用 teachingSections，學習進度與題目識別碼沿用原值。本目錄的教學資料與建置器已是正式建置依賴，不可當作無用檔案刪除。
